<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/HandDetection/raw/main/assets/icons/handDetection.png" width="40"/> Hand Detection</h1>

<p align="center">
 Hand Detection is a Python application that detects hands, tracks landmarks, and classifies gestures in real time.
</p>

![HandDetectionDemo](https://github.com/KrishBharadwaj5678/HandDetection/raw/main/assets/demos/HandDetectionDemo.png)

## <img src="https://github.com/KrishBharadwaj5678/HandDetection/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature                               | Description                                                     |
| ------------------------------------- | --------------------------------------------------------------- |
| 🔍 **Real time hand tracking**         | Detects hands in live video feed.                               |
| 🤖 **Hand classification**             | Classifies whether the detected hand is left or right.          |
| 🖌️ **Landmark visualization**         | Draws landmarks on the hand.                                     |
| ⚡ **Fast and efficient**             | Uses MediaPipe for optimal speed and performance.               |
| 📷 **Works with any webcam**          | Compatible with any standard webcam.                            |

## <img src="https://github.com/KrishBharadwaj5678/HandDetection/raw/main/assets/readme/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/HandDetection.git
```

### 2️⃣ Navigate to the Project

```bash
cd HandDetection
```

### 3️⃣ Install the required libraries

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the script

```bash
python app.py
```
