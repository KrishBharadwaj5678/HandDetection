<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/HandDetection/raw/main/assets/icons/handDetection.png" width="40"/> Detecção de Mãos</h1>

<p align="center">
  Aplicação em Python que detecta mãos, rastreia pontos de referência e classifica gestos em tempo real.
</p>

![HandDetectionDemo](https://github.com/KrishBharadwaj5678/HandDetection/raw/main/assets/demos/HandDetectionDemo.png)

## <img src="https://github.com/KrishBharadwaj5678/HandDetection/raw/main/assets/readme/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
| -------------- | --------- |
| 🔍 **Rastreamento de mãos em tempo real** | Detecta mãos em um fluxo de vídeo ao vivo. |
| 🤖 **Classificação das mãos** | Identifica se a mão detectada é esquerda ou direita. |
| 🖌️ **Visualização dos pontos de referência** | Exibe os principais pontos de referência da mão. |
| ⚡ **Rápido e eficiente** | Utiliza o MediaPipe para oferecer alto desempenho e processamento rápido. |
| 📷 **Suporte a webcam** | Compatível com webcams padrão. |

| Tecnologia | Finalidade |

## <img src="https://github.com/KrishBharadwaj5678/HandDetection/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clone o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/HandDetection.git
```

### 2️⃣ Acesse o Diretório do Projeto

```bash
cd HandDetection
```

### 3️⃣ Instale as Bibliotecas Necessárias

```bash
pip install -r requirements.txt
```

### 4️⃣ Execute a Aplicação

```bash

```
