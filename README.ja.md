<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/HandDetection/raw/main/assets/icons/handDetection.png" width="40"/> ハンド検出</h1>

<p align="center">
  Pythonを使用して、リアルタイムで手を検出し、ランドマークを追跡し、ジェスチャーを分類するアプリケーションです。
</p>

## <img src="https://github.com/KrishBharadwaj5678/HandDetection/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
| ---- | ---- |
| 🔍 **リアルタイム手追跡** | カメラのライブ映像から手をリアルタイムで検出します。 |
| 🤖 **手の分類** | 検出した手が左手か右手かを判別します。 |
| 🖌️ **ランドマークの可視化** | 手の主要なランドマークを画面上に表示します。 |
| ⚡ **高速・効率的** | MediaPipeを使用して、高速かつ効率的な処理を実現します。 |
| 📷 **ウェブカメラ対応** | 一般的なウェブカメラで使用できます。 |

## <img src="https://github.com/KrishBharadwaj5678/HandDetection/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/HandDetection.git
```

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd HandDetection
```

### 3️⃣ 必要なライブラリをインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリケーションを起動

```bash
python app.py
```
