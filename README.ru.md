<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/HandDetection/raw/main/assets/icons/handDetection.png" width="40"/> Обнаружение рук</h1>

<p align="center">
  Python-приложение для обнаружения рук, отслеживания ключевых точек и классификации жестов в реальном времени.

## <img src="https://github.com/KrishBharadwaj5678/HandDetection/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| ----------- | -------- |
| 🔍 **Отслеживание рук в реальном времени** | Обнаруживает руки в видеопотоке с камеры. |
| 🤖 **Классификация рук** | Определяет, является ли обнаруженная рука левой или правой. |
| 🖌️ **Визуализация ключевых точек** | Отображает ключевые точки на руке. |
| ⚡ **Быстрая и эффективная работа** | Использует MediaPipe для высокой скорости и производительности. |
| 📷 **Поддержка веб-камеры** | Совместимо со стандартными веб-камерами. |

## <img src="https://github.com/KrishBharadwaj5678/HandDetection/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/HandDetection.git
```

### 2️⃣ Переход в директорию проекта

```bash
cd HandDetection
```

###  3️⃣ Установка необходимых библиотек

```bash
pip install -r requirements.txt
```

### 4️⃣ Запуск приложения

```bash
python app.py
```
